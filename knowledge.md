# COTS Monitor - Project Knowledge

## Project Overview

COTS Monitor is a Flutter-based application developed for our capstone project. The system is designed to help detect, monitor, and manage Crown-of-Thorns Starfish (COTS) in marine environments.

## Technologies Used

- Flutter and Dart
- Firebase
- Computer Vision / YOLOv8
- Git and GitHub

## Main Features

- COTS detection using images
- Detection history and records
- Location and monitoring
- Expert review of detections
- COTS removal status tracking
- User-friendly mobile interface

## Project Guidelines

- Follow the existing Flutter project structure.
- Keep the user interface simple and accessible.
- Reuse existing components when possible.
- Avoid unnecessary changes to working features.
- Check existing code before adding new functions.
- Test changes before committing them.

## Custom Skills

2. cots-ui-design

## Project Goal

The goal of this project is to support COTS monitoring and help authorized users manage detection records and removal activities.
